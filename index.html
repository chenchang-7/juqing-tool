Claude 接口设置

怎么用?没连上怎么办?
使用前必须先在自己电脑上启动「本地中转」(双击运行 local-relay 启动文件,看到「本地中转已启动」即可,窗口别关)。

密钥 / Token 就是你 Claude Code 里用的那个(ANTHROPIC_AUTH_TOKEN,通常在 ~/.claude/settings.json 里)。

若点生成后报「Failed to fetch」,基本是本地中转没启动或已关闭,重新启动即可。

密钥只存在你自己的浏览器里,不上传到本页所在的服务器。
